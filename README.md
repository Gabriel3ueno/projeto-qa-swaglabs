# 🧪 Projeto QA - Testes Manuais Funcionais (SwagLabs)

## 📌 Sobre o projeto
Este projeto tem como objetivo demonstrar na prática o dia a dia de um QA, aplicando conceitos de qualidade de software em um contexto ágil (**Scrum**).  
O sistema utilizado como base foi o **SwagLabs (saucedemo.com)**.

---

## 🎯 Objetivo
Aplicar:
- Levantamento e análise de requisitos  
- Escrita de User Stories  
- Planejamento de testes  
- Execução de testes manuais  

---

## 🔄 Fluxo de Trabalho
**Backlog → Refinamento → Ready → Em Desenvolvimento → Em Teste → Done**  
**Bug → Em Correção → Reteste → Done**

---

## 👤 User Stories
### ✅ US01 - Login
Como cliente, quero acessar minha conta para utilizar a plataforma.

### ✅ US02 - Carrinho
Como cliente, quero adicionar produtos ao carrinho para realizar compras.
